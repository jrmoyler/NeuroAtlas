# NeuroAtlas

NeuroAtlas is a futuristic educational web application for exploring biological
intelligence across species. It combines a premium mission-control interface
with interactive 3D anatomical visualizations, comparative dashboards, guided
learning missions, and a scalable species content system.

## Tech stack

- Next.js
- React
- Tailwind CSS
- Three.js with React Three Fiber
- Framer Motion
- Zustand

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to explore the NeuroAtlas interface.
